把 BZD 会员资料接入你自己的 AI

适用于 BZD 文库会员、BZD 智库会员（卡密以 BZDWK- 或 BZDZK- 开头）

接入后，你可以在自己常用的 AI 里直接问："根据 BZD 资料，熵权法有哪些坑？""美赛 O 奖论文的灵敏度分析一般怎么写？"，AI 会去查 BZD 的资料再回答，并告诉你出处。

竞赛资料卡（BZDSJ / BZDSA / BZDSF）不支持接入 AI。

有两种方式，任选一种：

方式一：下载资料再上传方式二：MCP 接口
适合谁所有人，什么 AI 都能用会用 Cherry Studio / Cursor / Claude 等工具的同学
难度最简单，下载后上传文件填一次配置
资料更新需要重新下载自动同步，永远是最新
阅读——不限次
下载公开资料不限；内部资料每天 30 个同左（与网站下载合计 30 个）

方式一：下载资料，上传到你自己的 AI（推荐新手）

第 1 步：下载

  1. 打开 https://kb.bzdshumo.com，点「BZD 文库会员」或「BZD 智库会员」，输入你的卡密登录。
  2. 公开资料：点顶部「公开资料」，在想要的项目旁点 「一键下载整项」，得到一个 .zip 压缩包，解压即可。不限次数。
  3. 内部资料：点顶部「内部资料」，展开项目后逐个点「下载」。每天最多 30 个；只想看内容的话点「查看」，在线查看不限次。

第 2 步：上传到你的 AI

大部分 AI 支持直接上传 PDF、Word、Markdown 文件。

腾讯 ima

  1. 打开 ima → 左侧「知识库」→ 新建知识库，起名"BZD 资料"。
  2. 点「上传文件」，选择刚下载的文件（可以多选）。
  3. 之后在 ima 对话时选择这个知识库提问即可。

Kimi / 豆包 / 通义千问

  1. 在对话框点 📎（上传文件），选择下载好的文件。
  2. 直接提问，例如："根据这份资料，层次分析法的一致性检验怎么做？"（这类 AI 每次新对话需要重新上传文件。）

ChatGPT

  1. 左侧「项目 Projects」→ 新建项目 → 「添加文件」，上传 .md。
  2. 在这个项目里新建对话提问，AI 会自动参考文件。

Claude

  1. 左侧「Projects」→ 新建 → 「Add content / 添加内容」→ 上传 .md。
  2. 在项目里提问。

扣子 Coze

  1. 「资源库」→ 新建「知识库」→ 选「文本格式」→ 上传 .md。
  2. 在你的智能体里「知识」→ 添加这个知识库。

方式二：MCP 接口（AI 实时查资料）

MCP 是一种让 AI 直接"调用"外部资料库的方式。配好之后，你的 AI 每次回答前会自己去 BZD 资料库检索原文，资料更新了也不用重新下载。

需要填写的三项：

项目填写
类型Streamable HTTP（有的软件叫「可流式传输的 HTTP」）
地址https://kb.bzdshumo.com/mcp
请求头Authorization: Bearer 你的卡密

把"你的卡密"换成你自己的完整卡密，例如 Bearer BZDZK-ABCD-EFGH-JKLM，注意 Bearer 和卡密之间有一个空格。

Cherry Studio（推荐，免费、支持国产模型）

  1. 打开 Cherry Studio → 左下角「设置」→ 「MCP 服务器」 → 「添加服务器」。
  2. 名称填 BZD资料库，类型选 「可流式传输的 HTTP（streamableHttp）」。
  3. URL 填 https://kb.bzdshumo.com/mcp。
  4. 请求头填：Authorization=Bearer 你的卡密。
  5. 保存，确认状态显示为已连接（绿色）。
  6. 回到对话，在输入框下方的工具图标里勾选 BZD资料库，然后提问。

Cursor

  1. Settings → MCP → 「Add new MCP Server」。
  2. 粘贴下面的配置（把"你的卡密"换掉），保存：
{
  "mcpServers": {
    "bzd-shumo": {
      "type": "streamableHttp",
      "url": "https://kb.bzdshumo.com/mcp",
      "headers": { "Authorization": "Bearer 你的卡密" }
    }
  }
}

Claude Code（命令行）

claude mcp add --transport http bzd-shumo https://kb.bzdshumo.com/mcp --header "Authorization: Bearer 你的卡密"

接入后 AI 能做的事

你的 AI 会自动使用这些工具，不需要你手动调用：

工具作用次数
list_files浏览公开资料、内部资料的目录和文件不限
read_file在线阅读某个文件的全文不限
download_file获取下载链接（10 分钟内有效，只能用一次）内部资料每天 30 个（与网站合计），公开资料不限
search / read_document 等全文检索（检索库上架后可用）不限
提问小技巧：在问题里加一句"请先在 BZD 资料库里查找并阅读相关文件"，AI 会更积极地查资料。只想参考内容时，让 AI"阅读"而不是"下载"，这样不消耗下载次数。

常见问题

Q：提示「缺少卡密」或「卡密不存在」？

检查请求头是否写成 Authorization: Bearer 你的卡密，Bearer 后面有空格，卡密前后不要有多余空格。

Q：提示「竞赛资料卡不支持接入 AI」？

只有文库会员、智库会员卡可以接入。竞赛资料请在网站上查看和下载。

Q：提示「资料库正在整理上架中」？

会员资料还在上架，上架后即可检索。

Q：每天的次数用完了？

只有内部资料下载有限制：每天 30 个，网站下载和 AI 下载合计，第二天零点恢复。在线查看、AI 阅读都不限次；如果提示"调用太频繁"，等几秒再试即可（每分钟最多 60 次，防止程序刷取）。

Q：可以把卡密给同学用吗？

不可以。卡密就是你的接入密钥，下载和阅读到的内容都带有你的会员标识，仅限本人学习使用。发现外泄的卡密会被停用。

Q：这会消耗我的 AI 额度吗？

会。资料由 BZD 提供，但"读资料、组织回答"用的是你自己 AI 的模型和额度。
